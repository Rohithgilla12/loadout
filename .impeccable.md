# Design Context — Loadout

## Target audience
Power users of AI coding agents (Claude Code, Cursor, Codex): developers with 10+ skills installed across multiple agents. Expert users who live in terminals and IDEs, value speed and density, and judge tools in the first 10 seconds.

## Use cases
- See every installed skill across every agent at a glance (one screen of truth)
- Create/switch profiles (named skill sets) per project, instantly
- Review and trust-check skills before installing; update with diff + rollback
- Share a loadout with the team (committed loadout.json) or publicly (web share page)

## Brand personality / tone
**Industrial workbench.** Precise, dense, keyboard-friendly, fast — the data-peek lineage. The "loadout" metaphor is equipment and readiness, not gaming kitsch: think tool chests, flight cases, kit checklists. Calm confidence; the tool gets out of the way.

## Visual direction
- **Type:** IBM Plex Sans (body/UI), IBM Plex Mono for genuinely technical values (SHAs, paths, counts) only. Display moments use Plex Sans with tight tracking and heavy weights.
- **Color:** warm paper-tinted light theme (oklch-tinted neutrals, never pure white/black), ink text, one sharp accent: safety orange (~oklch(0.68 0.19 42)). Status colors muted and functional.
- **Layout:** dense tables with generous section separation; left-rail nav; asymmetric two-pane detail views. No card grids, no glassmorphism, no dark-with-neon.
- **Motion:** minimal and stateful — fast ease-out transitions on selection/toasts only.

## Constraints
Tauri 2 webview (desktop), React + Tailwind v4. Web app (marketing/share) shares the same identity, can be more expressive/editorial.
